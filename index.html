wcli

Terminal devtools over the raw Chrome DevTools Protocol — not a wrapper around a summarized client. Network, DOM, storage, console, debugger, CPU profiles, plus a persistent Burp-style interceptor. Built to be driven by agents as much as by people.

wcli

0.3.0

Every command takes --json and hands back unfiltered protocol-level output you can pipe into jq; without it you get a colored table. wcli schema describes all 22 commands to an agent, and every error is machine-readable.

Built for agents

The repo ships its own AGENTS.md and skill/SKILL.md. Raw CDP instead of a client wrapper, structured output on every verb, and a JSON error contract — an agent can drive the whole thing without scraping stdout.

It also vendors its own browser: --executable, then WCLI_CHROME_PATH, then a browsers/ directory, so it never assumes a system Chrome exists.

Or skip launching one entirely and attach to a Chrome you already have open with --connect 9222.

HoloBridge

A type-safe bridge between websites and Discord bots — every Discord operation over REST, every event over a WebSocket, and a plugin system to extend both. The most thoroughly documented repo on the account.

01

Build the missing piece. Own copyright engine, own analytics, own file host, own browser bridge, own launcher. Depending on a service is a decision I make deliberately, not by default.

02

Interfaces that agents can drive. Structured output on every command, schema endpoints, documented error contracts. A human gets a readable table; a program gets the same data untouched.

03

State the limits in the README. Gappa is offline because it makes no money. wcli vendors its own browser instead of assuming a system Chrome exists. Both say so instead of leaving you to find out.

04

Reach for the right language each time. Minecraft tooling in Java for the mods and Rust for the launcher; copyright checking in three languages because each consumer wanted a different one.

05

Ship free, and say so out loud. Everything public here is free, and the rate limits exist to keep services fast rather than to upsell you.
